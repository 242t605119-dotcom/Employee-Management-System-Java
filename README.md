# Employee Management System (Java)

## Description

This is a simple Java program used to store and manage basic employee details like employee ID, name, department and salary.

## Features

- Add Employee
- View Employee
- Update Salary
- Exit

## Technologies Used

- Java
- Scanner

## How to Run

Compile:

javac EmployeeManagement.java

Run:

java EmployeeManagement
